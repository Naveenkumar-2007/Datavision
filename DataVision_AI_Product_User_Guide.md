## 02 The Problem We Solve

Traditional Business Intelligence (BI) tools require months of data engineering, complex SQL queries, and dedicated data science teams. DataVision AI eliminates these bottlenecks by providing:
- **Instant Insights**: No manual SQL or chart configuration required.
- **Zero-Hallucination Analytics**: Strictly grounded data processing using verified SQL execution and RAG vector retrieval.
- **Unified Platform**: Analytics, AutoML, Computer Vision, Scenario Simulation, and Vector Search in one unified suite.

## 04 Step-by-Step Autonomous Workflow

1. **Connect & Upload**: Upload CSV, Excel, Images, or connect your PostgreSQL/MySQL database.
2. **Automatic Cleaning & Ingestion**: Data Janitor normalizes schema, fills missing values, and detects column data types.
3. **Multi-Agent Processing**: Collaborative tools run statistical analysis, anomaly detection, pattern discovery, and predictive modeling.
4. **Interactive Visualization**: Boardroom-ready charts and reports generated instantly.

## 07 Admin Dashboard & PostgreSQL Database Management

Access `/admin` to monitor system activity, active user sessions, database health, and workspace memberships.

### How to Inspect the PostgreSQL Database
- **Admin Dashboard**: Open `/admin` in the browser.
- **CLI Connection**: `psql -U postgres -d datavision`
- **ORM Schema**: Managed via SQLAlchemy AsyncSession in `backend/database/orm.py`.

## 09 Enterprise Security & Provider Cascade Shielding

## 10 Deployment & Infrastructure Setup

DataVision AI is containerized with Docker and ready for single-click deployment to Hugging Face Spaces or AWS/Render.

```bash
# Build locally
docker build -t datavision-ai .

# Run container
docker run -d -p 7860:7860 datavision-ai
```
